## About

**NordiummOptimizer** is a Minecraft Fabric optimization project focused on reducing unnecessary client-side rendering work.

The goal is to make Minecraft render more intelligently by avoiding wasted processing on objects that do not contribute to the current frame while keeping gameplay unchanged and remaining fully client-side.

This project explores:

- Java development
- Minecraft's rendering pipeline
- Fabric modding
- Performance optimization techniques
- Client-side rendering systems

## How It Works

NordiummOptimizer focuses on reducing unnecessary rendering work.

Instead of changing gameplay or modifying server behavior, the mod aims to analyze what needs to be rendered and optimize the client-side workload.

The goal:

> If something cannot affect the current frame, avoid spending resources rendering it.
